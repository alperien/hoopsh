items (W1–W67). Rows are appended per landing and never renumbered; resolved
rows keep their record in place — the register is the project's memory of
what was measured, decided, and deferred.

Provenance: split 2026-07-29 out of `REFACTOR.md`, the working log of the
`refactor/verification-and-debt` branch (register reconciled 2026-07-27
against the wave-2 audit). Code comments and commit messages citing
"REFACTOR.md W\<n\>/D\<n\>" refer to rows here. The branch narrative —
baseline, outcome summary, the Phase-5 finding, M1, gate-tier baselines, and
the finding→commit traceability map — is
[history/refactor-log.md](./history/refactor-log.md).

Citation convention: out-of-repo citations in Source columns ("…survey",
"design-…" / "b2-…" / "findings/scan/…" findings) follow the branch
commit-message convention — the swarm run's findings files.
