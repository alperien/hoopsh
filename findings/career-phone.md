## What is done well
- The ghost guard is defense-in-depth done right: phase gate + commitment gate + year-aware event corroboration (events carry (year, week)) closing the exact stale-lastMoveWeek resurrection bug the header describes — and the tests attack it three ways, including a forged fresh event against the phase guard (phone.test.ts:234-289).
- Once-ever memory derived from message ids ('#tag#' + alreadySent) is an elegant zero-new-state design: save/load-stable by construction, burst-safe (siblings share a tag within one week's generation), and it makes scan-based detections (a draft tx that stays in the ledger forever) fire exactly once — proven by test for commit, draftnight, undrafted, debut, kept-promise.
- Draw discipline is clean and honestly documented: exactly one int draw per ADMITTED message in a fixed admission order, with admission a pure function of state (career.phone itself included), single-draw pick/chance streams for stable program personalities, no gaussians. Byte-identity is tested twice (rich week, draft night) and holds under review — no iteration-order hazards found anywhere in the module.
- The cap-exemption rationale encodes a measured bug ("a cap that silences the biggest night of a career") at the site, and the family-cap-exhaustion test proves signing day still lands after mom's budget is spent — the right test for the right invariant.
- State-backed plumbing is real where it matters most: grade notes quoted verbatim from GameGrade.note, adherence/production numbers from the actual grade, box lines from the folded record with the [home, away] convention handled correctly at every site, mock-vs-pick gaps arithmetically exact in all four draft-night branches.
- applyPhoneChoice's error paths are exemplary: never throws, mutates nothing on any refusal (snapshot-tested), answered-once-forever, and every mutation appends a reasoned event for the explained-consequence lint.
- The one-week-lag windows (eventsWithinWeeks, back=1, absolute weeks) are exactly right for both timing shapes the tick produces: post-pass folds land at diff 1, post-increment year-wrap harvests at diff 0 then blocked at diff 1 — a subtle piece of clock reasoning that holds.
