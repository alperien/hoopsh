## What is done well
- The circle method is textbook-correct where it is used: enumeration confirms every pairing exactly once per cycle for 8/10/12 teams, perfect per-team game counts, PERFECT home/away splits over the shipped double round robins (7/7, 9/9, 11/11), one game per team per round, 1-2 games per team-week, unique ids, monotone absolute weeks — and the cycle-parity polarity flip that returns fixtures to the other gym is a genuinely elegant one-liner.
- Determinism discipline is real, not aspirational: one derived stream per subsystem, fixed draw order documented and honored (name-pool shuffle, slot qualities, rosters in team order; per-player age → generatePlayer → name re-rolls), standings-deterministic seeding that draws nothing, the national at-large draw on its own registered stream, and a byte-identity rebuild test proving it.
- Fail-loud culture in the fold: duplicate results, unknown games, unknown players, missing standings rows all throw with named ids; the refold guard is unit-tested; the defensive id suffix in buildRoundRobin is labeled as unreachable-with-shipped-params rather than silently trusted.
- The minutes sheet is a mechanism, not a label: the role's target rides the engine's real minutes controller, scaled honestly to the pack's game length (verified against subs.ts's pack-aware pace math), the whole-team waterfall is exact by construction (weights descend; caps return overflow to the pot), and the module comment records the measured failure (16.7 garbage-role minutes) that forced the whole-sheet design plus the measured role gradient that validated it.
- Seed hygiene is doubly safe: circuit games run under `${career.seed}:circuit:<gameId>` while the embedded league runs under `${career.seed}:world:game:<id>` — distinct label AND distinct root.
- The rule-pack plumbing holds end to end: prep quarters label Q, NCAA halves label H, OT derives from folded periods rather than a flag, and pace normalizes by periods x periodMinutes exactly as CAREER_INTERNALS claims (gameday.ts:437, :276-281, :482).
- The test file's compute-budget header (one engine-real season, run once / assert many, hand-fed brackets for controlled propagation) is a model of honest cost discipline, and its score-band provenance note documents its own drift instead of silently widening.
